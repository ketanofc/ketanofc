## Current Project

### [iFeelPDF](https://ifeelpdf.lol/) 📄

**Simple PDF tools that just work.**

iFeelPDF is a browser-first PDF utility platform designed to make everyday PDF tasks simple, fast, and accessible.

The idea is straightforward:

> **PDF tools should feel like a great consumer product, not complicated enterprise software.**

iFeelPDF focuses on:

* Simple and intuitive PDF tools
* Fast workflows with minimal friction
* Privacy-conscious file processing
* Clean, distraction-free interfaces
* Useful utilities without unnecessary complexity

## Philosophy

I believe good software should be:

**Simple** → Easy to understand from the first interaction.

**Useful** → Solve a real problem instead of adding complexity.

**Fast** → Get users to the outcome with as little friction as possible.

**Thoughtful** → Good engineering and good design should work together.

**Accessible** → Technology should feel approachable, not intimidating.
